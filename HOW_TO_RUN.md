
# How to Run the Digital Logic Truth-Table Generator

## Requirements

- Python 3

## Steps

1. Open the file `digital_logic_truth_table.py`.
2. Copy the Python code.
3. Open an online Python compiler, such as Programiz.
4. Paste the code into the editor.
5. Press Run to execute the program.
6. Check the truth tables for AND, OR, XOR, NAND, NOR, and NOT gates.

## Expected Result

The program displays the truth-table outputs for all six logic gates.

## Learning Outcome

This project demonstrates basic Python programming and digital logic concepts.
